PANDUAN FORMAT

Mengenal format CDR, SVG, DXF, EPS, dan PDF

Setiap format memiliki kegunaan dan kompatibilitas berbeda. CDR umum digunakan dalam CorelDRAW. SVG merupakan format vector berbasis XML yang banyak didukung aplikasi desain dan web. DXF sering dipakai untuk pertukaran data CAD dan sebagian alur CNC/laser. EPS adalah format pertukaran vector yang masih digunakan di berbagai aplikasi. PDF dapat memuat vector maupun raster, jadi periksa isi dokumennya.

Periksa sebelum membeli

  • Pastikan aplikasi yang Anda gunakan dapat membuka format tersebut.
  • Untuk cutting atau CNC, periksa skala, garis terbuka, objek ganda, dan detail terlalu kecil.
  • Jangan menganggap semua file DXF/SVG otomatis siap mesin; lakukan uji pada perangkat dan material Anda.
