PANDUAN FORMAT

Mengenal format file vector CDR, SVG, DXF, EPS, dan PDF

File desain vector tersedia dalam beberapa format. Masing-masing memiliki fungsi, dukungan aplikasi, dan batasan berbeda. Memilih format yang tepat membantu menjaga hasil desain saat dibuka, diedit, dibagikan, atau diteruskan ke proses produksi.

CDR untuk pekerjaan CorelDRAW

CDR adalah format dokumen asli CorelDRAW. Format ini cocok untuk menyimpan pekerjaan yang masih perlu diedit di CorelDRAW. Kompatibilitas dapat bergantung pada versi aplikasi dan fitur yang digunakan.

SVG untuk grafis digital dan web

SVG merupakan format vector berbasis XML yang banyak digunakan untuk ikon, logo, ilustrasi, dan elemen grafis web. Dukungan fitur tertentu dapat berbeda antar aplikasi, sehingga file sebaiknya diperiksa setelah diimpor.

DXF untuk pertukaran data CAD

DXF umum digunakan untuk pertukaran gambar teknis dan dapat menjadi bagian dari alur CNC atau laser. Pastikan satuan, skala, jenis garis, dan geometri sesuai dengan software serta mesin tujuan.

EPS dan PDF untuk pertukaran dokumen

EPS masih digunakan sebagai format pertukaran grafis pada sejumlah aplikasi. PDF praktis untuk berbagi dan alur cetak, tetapi PDF dapat memuat vector maupun raster. Periksa isi dokumen sebelum menganggapnya sebagai file vector yang dapat diedit.

Checklist sebelum menggunakan file

  • Pastikan aplikasi tujuan mendukung format dan versi file.
  • Periksa font, warna, ukuran halaman, dan skala desain.
  • Untuk cutting atau CNC, cek garis terbuka, objek ganda, kontur, serta detail yang terlalu kecil.
  • Lakukan uji pada software dan perangkat produksi yang akan digunakan.
  • Periksa lisensi dan hak penggunaan aset.

Jangan memilih format hanya berdasarkan ekstensi. Pastikan isi file dan kecocokannya dengan alur kerja Anda.
