FORMAT VECTOR

Apa itu SVG dan kapan menggunakannya?

SVG adalah format grafis vector yang menyimpan bentuk melalui deskripsi geometri, bukan susunan piksel seperti gambar bitmap. Karena itu, SVG dapat diskalakan untuk banyak ukuran tanpa tepi menjadi pecah, selama kontennya memang berupa elemen vector.

Kegunaan SVG

SVG sering dipakai untuk ikon, logo, ilustrasi web, diagram, dan aset digital yang perlu tampil tajam pada ukuran layar berbeda. File ini juga dapat dibuka atau diimpor oleh sejumlah aplikasi desain, tetapi fitur yang didukung dapat berbeda antar aplikasi.

Yang perlu diperiksa sebelum memakai

  • Pastikan file terbuka dengan benar pada aplikasi tujuan.
  • Periksa font; ubah teks menjadi kurva bila perlu menjaga bentuk tampilan.
  • Periksa warna, ukuran halaman, clipping, dan elemen transparan.
  • Untuk cutting, cek jalur terbuka, garis tumpang tindih, dan skala.

SVG bukan pengganti semua format

Mesin produksi atau aplikasi tertentu mungkin memerlukan DXF, CDR, PDF, atau format lain. Pilih format sesuai alur kerja, lalu uji file pada software dan perangkat yang akan digunakan. Jangan menganggap satu format otomatis cocok untuk semua mesin.

Gunakan SVG ketika alur kerja digital mendukungnya dan Anda membutuhkan vector yang mudah diskalakan. Untuk kebutuhan produksi, konfirmasikan kompatibilitas dan lisensi terlebih dahulu.
