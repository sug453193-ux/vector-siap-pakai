# Folder Vector Gratis

Simpan file vector gratis yang siap dibagikan di folder ini.

Format yang dapat ditambahkan: SVG, CDR, EPS, PDF, AI, PNG, atau ZIP.

Gunakan nama file yang jelas, misalnya `ornamen-islami-gratis.svg` atau `mihrab-vector-gratis.zip`.

Catatan: file yang diunggah ke folder ini belum otomatis tampil sebagai produk di halaman website. Setelah file diunggah, tautan unduhan dan tampilan katalog dapat ditambahkan pada halaman Koleksi Vector Gratis.
